# แผนหน้ารายการบ้านและปฏิทินหลายบ้าน

ตามโฟลว์ที่ผู้ใช้อนุมัติ: รายการบ้าน → ปฏิทิน → เปลี่ยนบ้าน โดยคงเดือนและเตือนข้อมูลยังไม่บันทึก

- เพิ่ม metadata รูปและทำเลแบบ nullable ด้วย migration ใหม่ ไม่สร้างข้อมูลสมมติ
- สร้าง PropertyWorkspace และรายการบ้านที่ใช้ซ้ำได้ มีค้นหา ตัวกรองทำเล loading/error/empty state
- ส่งบ้านที่เลือกให้ PricingCalendar; remount เมื่อเปลี่ยนบ้านและคงเดือนที่ parent เพื่อไม่ปะปนช่วงวันหรือ draft
- เพิ่ม dialog เตือน draft ก่อนกลับรายการหรือเปลี่ยนบ้าน และ beforeunload สำหรับการออกจากเว็บ
- ทดสอบการเลือกบ้านและ API scope, การคงเดือน, การป้องกัน draft; ตรวจมือถือ lint และ build
